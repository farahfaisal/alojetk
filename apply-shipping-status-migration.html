تطبيق تحديث حالة "في الطريق"

تحديث تلقائي لحالة الطلب عند بدء رحلة السائق

📋 ما الذي سيتم تطبيقه؟
ستتغير حالة الطلب تلقائياً إلى "في الطريق" (shipping) بمجرد أن يبدأ السائق رحلة التوصيل.
1 افتح Supabase Dashboard

اذهب إلى:

https://supabase.com/dashboard

واختر مشروعك

2 افتح SQL Editor

من القائمة الجانبية:

  • اضغط على SQL Editor
  • اضغط New Query
3 انسخ محتوى Migration

افتح الملف التالي من مجلد المشروع:

supabase/migrations/20260202220000_add_shipping_status_and_auto_update.sql

وانسخ كل محتوياته

4 الصق وشغّل
  • الصق الكود في SQL Editor
  • اضغط زر Run أو Ctrl+Enter
  • انتظر حتى تكتمل العملية
5 تحقق من النجاح

شغّل الاستعلام التالي للتحقق:

SELECT routine_name FROM information_schema.routines WHERE routine_name IN ( 'start_delivery_trip', 'start_multi_delivery_trip', 'update_delivery_status_with_driver' );

يجب أن تظهر الدوال الثلاث ✅

✅ بعد التطبيق:
  • عند تعيين سائق للطلب → الحالة تتغير تلقائياً إلى 'shipping'
  • العميل يرى "السائق في الطريق إليك"
  • يُسجل كل تغيير في order_status_history
⚠️ ملاحظات مهمة:
  • تأكد من أخذ نسخة احتياطية قبل التطبيق
  • لا تقاطع العملية حتى تكتمل
  • إذا ظهر خطأ، راجع ملف التوثيق
