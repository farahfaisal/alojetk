# دليل إعداد مواقع المتاجر

## أهمية تحديد موقع المتجر بدقة

تحديد موقع المتجر (latitude & longitude) بدقة **ضروري جداً** لـ:

1. ✅ **حساب وقت التوصيل الدقيق** - بناءً على المسافة الفعلية
2. ✅ **حساب رسوم التوصيل الدقيقة** - بناءً على المسافة
3. ✅ **تحسين تجربة المستخدم** - معلومات دقيقة تزيد الثقة
4. ✅ **تقليل الشكاوى** - عدم وجود مفاجآت للعميل

---

## ماذا يحدث بدون موقع دقيق؟

### ❌ المشاكل:

1. **وقت توصيل تقريبي فقط** - يستخدم النظام وقت ثابت (30-45 دقيقة)
2. **رسوم توصيل غير دقيقة** - قد تكون أعلى أو أقل من الواقع
3. **تجربة سيئة للمستخدم** - رسالة تحذيرية تظهر للعميل
4. **عدم إمكانية تتبع السائق بدقة**

### ⚠️ ما يراه العميل:

```
⏱️ وقت التوصيل تقريبي
🏪 معلومات موقع المتجر غير محددة بدقة في النظام
```

هذا يقلل من ثقة العميل بالتطبيق!

---

## كيفية تحديد موقع المتجر

### الطريقة 1: استخدام Google Maps

1. افتح [Google Maps](https://maps.google.com)
2. ابحث عن عنوان المتجر
3. انقر بزر الماوس الأيمن على الموقع الدقيق للمتجر
4. اختر "ما الموجود هنا؟" أو "What's here?"
5. ستظهر الإحداثيات في الأسفل بصيغة: `24.7136, 46.6753`
   - الرقم الأول = latitude (خط العرض)
   - الرقم الثاني = longitude (خط الطول)

### الطريقة 2: استخدام موقع الويب

يمكنك استخدام مواقع مثل:
- [https://www.latlong.net](https://www.latlong.net)
- [https://gps-coordinates.org](https://gps-coordinates.org)

## تحديث موقع المتجر في قاعدة البيانات

### باستخدام Supabase Dashboard:

1. افتح [Supabase Dashboard](https://supabase.com/dashboard)
2. اختر مشروعك
3. اذهب إلى `Table Editor` > `vendors`
4. ابحث عن المتجر المطلوب
5. حدث الحقول:
   - `latitude`: مثال `24.7136`
   - `longitude`: مثال `46.6753`
6. احفظ التغييرات

### باستخدام SQL:

```sql
-- تحديث موقع متجر واحد
UPDATE vendors
SET
  latitude = 24.7136,
  longitude = 46.6753
WHERE id = 'uuid-of-vendor';

-- تحديث مواقع عدة متاجر
UPDATE vendors
SET
  latitude = 31.5000,
  longitude = 34.4500
WHERE store_name = 'اسم المتجر';
```

## التحقق من صحة الإحداثيات

بعد إضافة الإحداثيات، تحقق من صحتها:

### باستخدام SQL:

```sql
-- عرض جميع المتاجر بدون موقع محدد
SELECT
  id,
  store_name,
  address,
  latitude,
  longitude
FROM vendors
WHERE latitude IS NULL OR longitude IS NULL;

-- عرض جميع المتاجر مع مواقعهم
SELECT
  store_name,
  address,
  CONCAT(latitude, ', ', longitude) as coordinates
FROM vendors
WHERE latitude IS NOT NULL AND longitude IS NOT NULL;
```

## الأمر الإداري المقترح

لإنشاء صفحة إدارية تسمح بتحديث مواقع المتاجر بسهولة:

```typescript
// مثال على واجهة تحديث موقع المتجر
const updateVendorLocation = async (vendorId: string, lat: number, lng: number) => {
  const { error } = await supabase
    .from('vendors')
    .update({
      latitude: lat,
      longitude: lng
    })
    .eq('id', vendorId);

  if (error) {
    console.error('Error updating vendor location:', error);
    return false;
  }

  console.log('✅ تم تحديث موقع المتجر بنجاح');
  return true;
};
```

## التحقق التلقائي

يمكن إضافة دالة تلقائية للتحقق من المتاجر بدون مواقع:

```sql
-- دالة للتحقق من المتاجر بدون موقع
CREATE OR REPLACE FUNCTION check_vendors_without_location()
RETURNS TABLE (
  vendor_id uuid,
  store_name text,
  address text
) AS $$
BEGIN
  RETURN QUERY
  SELECT
    id,
    vendors.store_name,
    vendors.address
  FROM vendors
  WHERE latitude IS NULL OR longitude IS NULL;
END;
$$ LANGUAGE plpgsql;

-- استدعاء الدالة
SELECT * FROM check_vendors_without_location();
```

## ملاحظات مهمة

### ✅ نصائح:

1. **استخدم أرقام عشرية دقيقة** - على الأقل 6 خانات بعد الفاصلة
2. **تأكد من الموقع** - تحقق من الموقع على الخريطة قبل الحفظ
3. **حدث بانتظام** - إذا انتقل المتجر، حدث الموقع فوراً
4. **اختبر التطبيق** - بعد التحديث، افتح صفحة المتجر وتأكد من عدم ظهور رسالة التحذير

### ⚠️ تحذيرات:

1. **لا تستخدم إحداثيات عشوائية** - يجب أن تكون دقيقة
2. **لا تنسخ من متجر لآخر** - كل متجر له موقعه الخاص
3. **انتبه للترتيب** - latitude أولاً، ثم longitude

## الأسئلة الشائعة

### س: ماذا إذا كان المتجر في مكان غير موجود على Google Maps؟

**ج:** استخدم أقرب نقطة معروفة وأضف العنوان النصي الدقيق في حقل `address`.

### س: هل يمكن أن تكون الإحداثيات سالبة؟

**ج:** نعم، بعض المناطق تستخدم قيم سالبة. فلسطين تستخدم قيم موجبة دائماً.

### س: كم عدد الأرقام العشرية المطلوبة؟

**ج:**
- **للدقة العالية**: 6-8 خانات عشرية (مثال: `24.71356789`)
- **للدقة المقبولة**: 4-5 خانات عشرية (مثال: `24.7136`)

### س: ماذا يحدث إذا أخطأت في الإحداثيات؟

**ج:** سيتم حساب المسافة ووقت التوصيل بشكل خاطئ. يجب التصحيح فوراً.
