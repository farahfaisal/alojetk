### الخطوة 1: أضف المسار

في ملف `src/App.tsx`، أضف هذين السطرين:

http://localhost:5173/admin/vendor-locations

## 🎯 حالات الاستخدام العملية

### السيناريو A: تحديث جميع المتاجر

```bash
1. فعّل "عرض المتاجر بدون موقع فقط"
2. ستظهر قائمة بالمتاجر المطلوبة
3. اختر أول متجر
4. حدد موقعه بدقة
5. احفظ
6. سينتقل تلقائياً للمتجر التالي
7. كرر حتى تنتهي القائمة
```

### السيناريو B: تصحيح موقع متجر

```bash
1. ابحث عن اسم المتجر
2. اختره من النتائج
3. ستظهر العلامة في الموقع الحالي
4. اسحب العلامة للموقع الصحيح
5. احفظ
```

### السيناريو C: أنت في المتجر الآن

```bash
1. اختر المتجر من القائمة
2. اضغط "موقعي الحالي" 📡
3. سيتم تحديد موقعك تلقائياً
4. احفظ
```

## 🔍 كيف أعرف أن الموقع دقيق؟

### ✅ علامات الدقة:

1. **الإحداثيات معقولة**
   ```
   مثال صحيح: 31.5000, 34.4500
   مثال خاطئ: 0.0000, 0.0000
   ```

2. **العلامة في المكان الصحيح**
   - يجب أن تكون على باب المتجر
   - وليس في الشارع أو المبنى المجاور

3. **المدينة صحيحة**
   - تحقق أن الموقع في نفس المدينة المحددة

4. **الرسالة اختفت**
   - افتح صفحة المتجر في التطبيق
   - يجب ألا تظهر رسالة "معلومات موقع المتجر غير محددة"

## 📊 تتبع التقدم

### في النظام:
```
⚠️ يوجد 3 متجر بدون موقع محدد
```

### في Supabase:
```sql
SELECT
  COUNT(*) FILTER (WHERE latitude IS NOT NULL) as "مع موقع",
  COUNT(*) FILTER (WHERE latitude IS NULL) as "بدون موقع"
FROM vendors;
```

### النتيجة المثالية:
```
✅ جميع المتاجر لديها مواقع محددة
✅ بدون موقع: 0
```

## 🐛 حل المشاكل الشائعة

### ❌ المشكلة: الخريطة فارغة

**الأسباب المحتملة:**
- Google Maps API Key غير صحيح
- API غير مفعّل في Google Cloud

**الحل:**
```bash
# 1. تحقق من المفتاح
echo $VITE_GOOGLE_MAPS_API_KEY

# 2. فعّل Maps JavaScript API في:
# https://console.cloud.google.com/apis/library/maps-backend.googleapis.com

# 3. أعد تشغيل السيرفر
npm run dev
```

---

### ❌ المشكلة: لا يمكن الحفظ

**الأسباب المحتملة:**
- مشكلة في الاتصال بـ Supabase
- صلاحيات RLS غير صحيحة

**الحل:**
```sql
-- تحقق من الصلاحيات
SELECT * FROM vendors WHERE id = 'vendor-id';

-- إذا لم يعمل، تحقق من RLS
SELECT * FROM pg_policies WHERE tablename = 'vendors';
```

---

### ❌ المشكلة: "موقعي الحالي" لا يعمل

**الأسباب المحتملة:**
- المتصفح يمنع الوصول للموقع
- لست في وضع HTTPS

**الحل:**
1. اسمح بالوصول للموقع في المتصفح
2. استخدم `localhost` أو `https://`
3. أعد تحميل الصفحة
