🔧 إصلاح قاعدة البيانات

حل مشكلة الطلبات الخاصة

❌ المشكلة الحالية:

حقل product_id في جدول order_items لا يقبل القيم الفارغة (NULL)، مما يمنع إضافة الطلبات الخاصة.

✨ الحل:

تعديل بسيط في قاعدة البيانات لجعل حقل product_id يقبل القيم الفارغة.

هذا التعديل آمن تماماً ولن يؤثر على البيانات الموجودة.

ALTER TABLE order_items ALTER COLUMN product_id DROP NOT NULL;
✅ تم النسخ بنجاح!

📝 خطوات التطبيق:

  1. افتح Supabase Dashboard
  2. اضغط على SQL Editor من القائمة الجانبية
  3. انسخ الكود أعلاه والصقه في المحرر
  4. اضغط Run أو F5
  5. ستظهر رسالة نجاح ✅
  6. عد إلى التطبيق وجرب الطلب الخاص مرة أخرى!
